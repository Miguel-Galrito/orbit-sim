# Changelog

## 0.6.0 — Interactive simulation release

- Added a native Plotly animation player for Earth-centered trajectories.
- Added Play / Pause controls and a simulation-time slider.
- Added full-trajectory context so the future path remains visible during animation.
- Replaced truncated metric displays with explicit units and descriptive labels.
- Added a separate Sun–Earth–Moon N-body laboratory.
- Added solar-system-scale (AU) and Earth–Moon local-scale (10³ km) views.
- Added N-body animation controls and Earth–Moon separation analysis.
- Improved scenario validation for Earth-intersecting orbits.
- Expanded the portfolio roadmap and documentation.

## 0.5.0 — Mission-analysis release

- Added Hohmann transfer, plane-change and bi-elliptic calculations.
- Added a universal-variable zero-revolution Lambert solver.
- Added Plotly dashboard, presets, ground tracks and CSV export.

## 0.3.0 — Foundation release

- Added orbital-element/state-vector conversion.
- Added two-body RK4 propagation.
- Added J2 and simplified atmospheric drag models.
- Added tests and GitHub Actions CI.
